# 🤖 دستیار هوشمند تلگرام (چند مدل هوش مصنوعی، رایگان روی Cloudflare)

یک ربات تلگرامی همه‌کاره که با زیرساخت رایگان **Cloudflare Workers AI**
اجرا می‌شود — بدون سرور شخصی، بدون هزینه‌ی ثابت.

## ✨ امکانات

- چت با چند مدل هوش مصنوعی مختلف (Llama 3.3، Qwen، GLM، Gemma، GPT-OSS) و امکان جابه‌جایی بین‌شان با دستور `/model`
- ساخت تصویر با FLUX (پرامپت فارسی یا انگلیسی، ترجمه‌ی خودکار)
- تحلیل عکس با مدل Vision (فقط با فرستادن عکس)
- تشخیص گفتار: پیام صوتی بفرست، متنش استخراج و به چت داده می‌شود
- خواندن و تحلیل فایل‌های متنی/کد (txt, md, js, html, py, json و…)
- جستجوی زنده در وب برای پاسخ‌های به‌روز (اختیاری)
- حافظه‌ی مکالمه برای هر کاربر (با `/new` پاک می‌شود)
- محدود کردن ربات فقط به کاربران خاص (اختیاری)

## ✅ پیش‌نیازها

فقط دوتا چیز لازم داری، هر دو رایگان:

1. یک اکانت [Cloudflare](https://dash.cloudflare.com/sign-up) (نیازی به کارت بانکی نیست)
2. یک اکانت تلگرام

## قدم ۱: ساخت ربات تلگرام و گرفتن توکن

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده.
2. دستور `/newbot` را بفرست.
3. یک اسم و یک یوزرنیم (باید به `bot` ختم شود، مثل `my_ai_assistant_bot`) برایش انتخاب کن.
4. BotFather یک **توکن** به تو می‌دهد، شبیه:
   `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
   این را جایی کپی کن؛ در قدم بعد لازمت می‌شود.

## قدم ۲: نصب با یک کلیک روی Cloudflare
ابتدا از این ریپو یک فورک بساز 
سپس روی دکمه‌ی زیر بزن:

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/hhdoust2/tel-ai-bot)

> اگر دکمه کار نکرد، این آدرس را در مرورگر باز کن
بعد از باز شدن صفحه:

1. اگر در Cloudflare لاگین نباشی، ازت لاگین/ساخت اکانت رایگان می‌خواهد.
2. اکانت کلادفلرت را انتخاب کن.سپس قسمت git account گزینه new github connection را انتخاب کن و کلاد فلر را به گیتهاب و ریپو متصل کن
3. یک صفحه‌ی تنظیمات باز می‌شود و این مقادیر را از تو می‌پرسد:

   | فیلد | اجباری؟ | توضیح |
   |---|---|---|
   | `BOT_TOKEN` | ✅ اجباری | همان توکنی که در قدم ۱ از BotFather گرفتی |
   | `TAVILY_API_KEY` | اختیاری | برای جستجوی زنده‌ی وب. یک کلید رایگان از [tavily.com](https://tavily.com) بگیر. خالی بگذاری، این قابلیت غیرفعال می‌ماند و بقیه‌ی ربات عادی کار می‌کند |
   | `CF_API_TOKEN` | اختیاری | فقط برای نمایش وضعیت مصرف روزانه‌ی هوش مصنوعی در `/start` و `/model` |
   | `CF_ACCOUNT_ID` | اختیاری | همراه با `CF_API_TOKEN`، برای همان قابلیت بالا |
   | `ALLOWED_USER_IDS` | اختیاری | اگر می‌خواهی ربات فقط برای تو/چند نفر خاص کار کند، آی‌دی عددی تلگرامشان را با کاما جدا کن. خالی بماند یعنی ربات برای همه باز است |

4. روی **Deploy** بزن و چند لحظه صبر کن.

همین! کلادفلر خودش پشت‌صحنه:
- این کد را در یک ریپوی جدید در گیت‌هاب خودت کپی می‌کند (تا بعداً بتوانی شخصی‌سازی‌اش کنی)
- یک KV namespace برای حافظه‌ی مکالمه می‌سازد و بایند می‌کند
- دسترسی Workers AI را فعال می‌کند
- مقادیری که وارد کردی را به‌صورت امن ذخیره می‌کند
- ربات را دیپلوی می‌کند
هیچ کار دستی‌ای در پنل کلادفلر لازم نیست.

## قدم ۳: وصل کردن ربات به تلگرام (تنظیم Webhook)

بعد از پایان دیپلوی، کلادفلر یک آدرس شبیه این به تو می‌دهد:
`https://ai-multitask-bot.<subdomain>.workers.dev`

این آدرس را کپی کن و لینک زیر را با مقادیر خودت در مرورگر باز کن:

```
https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=<آدرس ورکر>
```

مثال:
```
https://api.telegram.org/bot123456789:AAExxxx/setWebhook?url=https://ai-multitask-bot.example.workers.dev
```

اگر پیام `{"ok":true,"result":true,...}` را دیدی، یعنی وصل شد. ✅

## قدم ۴: تست کن

به ربات تلگرامت برو و دستور `/start` را بفرست.

## 📋 دستورهای ربات

| دستور | کاربرد |
|---|---|
| `/start` | خوش‌آمد + وضعیت مصرف + مدل فعلی |
| `/model` یا `/models` | نمایش/تغییر مدل هوش مصنوعی |
| `/new`، `/clear` یا `/reset` | پاک‌کردن حافظه‌ی مکالمه و شروع تازه |
| `/agreevision` | تأیید یک‌بارهٔ لایسنس مدل تحلیل تصویر (قبل از اولین ارسال عکس لازم است) |

برای ساخت تصویر، از `/model` مدل «🎨 ساخت تصویر (FLUX)» را انتخاب کن و بعد توضیح تصویر را بفرست (فارسی یا انگلیسی).

## ⚙️ تغییر تنظیمات بعد از نصب

هر کدام از مقادیر بالا (`BOT_TOKEN`, `TAVILY_API_KEY`, ...) را بعداً هم می‌توانی از پنل Cloudflare عوض کنی:
`Workers & Pages → نام ورکرت → Settings → Variables and Secrets`

## 🔄 آپدیت گرفتن نسخه‌های بعدی

 با هر تغییر در ریپو ،اتوماتیک در ربات اعمال میشود

## 🛠 مشکل رایج

- **ربات جواب نمی‌دهد**: قدم ۳ (تنظیم Webhook) را دوباره چک کن.
- **خطای «مدل در دسترس نیست»**: با `/model` یک مدل دیگر انتخاب کن؛ گاهی یک مدل خاص موقتاً پرترافیک می‌شود.
- **جستجوی وب کار نمی‌کند**: یعنی `TAVILY_API_KEY` را وارد نکرده‌ای یا کلیدش منقضی شده — از پنل کلادفلر می‌توانی اضافه/عوضش کنی.
